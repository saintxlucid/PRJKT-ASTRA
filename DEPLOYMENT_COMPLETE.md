### Runtime Integration Template
```python
# In your llm_service.py or inference engine:
from ops.fusion_pipeline.scripts.runtime_hook_example import AstraRouter
from ops.fusion_pipeline.metadata.astra_metadata_min import AstraMetadataMin

# Initialize router
config = AstraMetadataMin()
router = AstraRouter(config=config)

# Process user input
def inference(user_prompt: str, memory_context: dict) -> str:
    # Pre-tokenization dispatch
    result = router.handle(user_prompt, memory_context)
    
    if result.get('routed'):
        # Modal dispatch occurred (vision/audio/code)
        tool_output = call_appropriate_tool(result)
        return tool_output
    else:
        # Text path - send to LLM with augmented prompt
        return llm.generate(result['prompt'], context=result['memory'])

# Audit logging

    audit_log = {
```

## 🎓 LEARNING RESOURCES

### How It Works
1. **Modal Dispatch**: AstraRouter analyzes pre-tokenization for [VIS], [AUD], [COD] markers
2. **Consent Gating**: Code operations checked against consent token; denial includes Sacred Code 333
3. **Memory Augmentation**: Episodic/semantic memory context injected into text prompts
4. **Audit Trail**: All significant operations logged with timestamp and context
5. **Fallback Path**: If no modality marker detected, content routes to standard LLM
