## GGUF Model Surgery Examples

This directory contains example notebooks demonstrating key features of the GGUF model surgery system:

1. `01_lora_merging.ipynb` - LoRA adapter merging with provenance
2. `02_rope_tuning.ipynb` - RoPE parameter tuning and validation
3. `03_schema_validation.ipynb` - Grammar-constrained output validation
4. `04_chamber_api.ipynb` - Using the HTTP API
