┌──────────────────────────────────────────────────────────────────────────────┐
│  EMERGENCY CONTACTS                                                          │
└──────────────────────────────────────────────────────────────────────────────┘

Rollback procedure:
1. ./deploy_hardened.sh stop
2. git checkout <previous-tag>
3. ./deploy_hardened.sh deploy

Disaster recovery:
1. ./deploy_hardened.sh stop
2. python scripts/restore.py
3. ./deploy_hardened.sh start

Circuit breaker stuck open:
- Wait for reset timeout (60s default)
- Or restart affected service

Leader election issues:
- Check Redis connectivity
- Verify lease TTL not too short
- Check for network partitions
