Problem: Smoke test fails
Solution: Check ASTRA services are running
  docker-compose ps
  curl http://localhost:8000/v1/system/health

Problem: p95 > 1000ms
Solution: Investigate slow endpoints in per-endpoint breakdown
  - Check Grafana dashboards for bottlenecks
  - Review Prometheus metrics
  - Scale up services if needed

Problem: High error rate (> 0.1%)
Solution: Check logs for 5xx errors
  docker-compose logs astra-master
  docker-compose logs memory-service

Problem: Throughput < target RPS
Solution: Increase workers or check system resources
  python tests/performance/test_load.py --workers 20

Problem: Connection errors
Solution: Increase connection pool size (edit test_load.py)
  connector = aiohttp.TCPConnector(limit=200, limit_per_host=100)
