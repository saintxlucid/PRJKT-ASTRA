TECHNICAL SPECIFICATIONS
─────────────────────────────────────────────────────────────────────────────

Embedding Model:
  Name: sentence-transformers/all-MiniLM-L6-v2
  Size: 22MB (fully local, no API calls)
  Dimensions: 384
  Device: CPU (GPU support via parameter)
  Batch Size: 32 (configurable)

Vector Database:
  Engine: ChromaDB
  Backend: DuckDB + Parquet (local file persistence)
  Indexing: HNSW (Hierarchical Navigable Small World)
  HNSW Params: M=16, ef_construction=200, space=cosine
  Collection: astra_knowledge

Document Management:
  TTL: 90 days (configurable)
  Batch Processing: 32-doc batches for efficiency
  Chunk Size: 1000 characters (paragraph-aware)
  Metadata: source, category, created_at, expires_at

Performance Characteristics:
  Embedding Latency: ~10-15ms per doc (batch)
  Retrieval Latency: ~50ms (P50), ~75-90ms (P95)
  Query Embedding: ~5-10ms
  Index Lookup: ~40-70ms
