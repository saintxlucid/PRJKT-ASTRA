================================================================================
                      MODAL DISPATCH REFERENCE
================================================================================

Once Phase B activated, system will handle 4 dispatch paths:

1️⃣ CODE DISPATCH
─────────────────────────────────────────────────────────────────────────────

Input: "<|code_start|>code_here<|code_end|> question"
Process:
  1. Router extracts code block
  2. Router checks: consent.allowed("code")
  3. If ALLOWED:
     - Execute: tool_bus.execute("code.apply_plan_or_summarize", payload)
     - Return: Tool result (optimized code, analysis, etc.)
  4. If DENIED:
     - Return: "❌ Consent required for code operations. (Sacred Code: 333)"

Sacred Code: Embedded in denial message + audit log

2️⃣ VISION DISPATCH
─────────────────────────────────────────────────────────────────────────────

Input: "<|vision_start|>description<|vision_end|> question"
Process:
  1. Router extracts vision content
  2. No consent check needed (safe)
  3. Execute: tool_bus.execute("vision.describe_or_answer", payload)
  4. Return: Vision analysis result

Sacred Code: Embedded in audit log

3️⃣ AUDIO DISPATCH
──────────────────────────────────────────────────────────────────────────────

Input: "<|audio_start|>audio_data<|audio_end|> question"
Process:
  1. Router extracts audio content
  2. No consent check needed (safe)
  3. Execute: tool_bus.execute("audio.transcribe_or_analyze", payload)
  4. Return: Transcription or analysis result

Sacred Code: Embedded in audit log

4️⃣ TEXT DISPATCH (Memory-Augmented)
──────────────────────────────────────────────────────────────────────────────

Input: Regular text prompt (no special markers)
Process:
  1. Router detects no markers
  2. Retrieves: memory.retrieve_relevant(prompt, top_k=6)
  3. Augments: prepend memory facts to prompt
  4. Generates: llm.generate(augmented_prompt, max_tokens=512)
  5. Return: LLM response with context

Sacred Code: Embedded in audit log

Example:
  Input: "What's the best approach for this?"
  Memory retrieved: "Previous discussion: Approach A is fast but risky..."
  Augmented: "<memory>...facts...</memory>\n\nWhat's the best approach?"
  Output: LLM response using context
