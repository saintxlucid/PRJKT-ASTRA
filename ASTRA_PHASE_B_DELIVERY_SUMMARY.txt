## 🆘 EMERGENCY RESPONSE

### If Validator Gates FAIL

Use the **Gate-Failure Fix Matrix** in QUICK_REFERENCE_CARD.txt:
- Identify which gate failed
- Find root cause in table
- Apply 5-minute fix (typical)
- Re-run validator
- Reconvene at 09:50 AM

### If Canary FAILS

Example failure: CODE canary doesn't trigger consent block
1. Check: Is consent.allowed() being called in tool_bridge_service.py?
2. Fix: Add consent check if missing
3. Restart service
4. Re-run canary
5. If still fails: Consider rollback

### If Metrics FAIL

Example: Latency p95 > 1050ms
1. Root cause: Quantization too heavy?
2. Fix: Switch quant from q4_k_m to q5_k_m
3. Restart
4. Re-test
5. If still over threshold: Consider rollback

### If CRITICAL FAILURE

One command rollback (<1 min):
```powershell
pwsh ops\fusion_pipeline\scripts\07_roll_back.ps1
```

This will:
1. Restore backup GGUF
2. Revert symlink
3. Restart services
4. Verify health

Then:
1. Post incident review (what broke?)
2. Fix root cause
3. Re-run validator
4. Reschedule deployment
