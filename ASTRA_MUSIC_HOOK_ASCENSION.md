### 🥁 Drum Architecture

#### Kick
- **Source:** Sub-heavy 808 (sine-based)
- **Pitch:** C1 (32 Hz fundamental)
- **Glide:** 120ms downward sweep
- **Dynamics:** No sidechain (front-loaded attack)
- **MIDI:** C note, 80% velocity

#### Hi-Hat Pattern
- **Style:** UK drill swing (triplet rolls on 1/24 grid occasionally)
- **Open Hat:** Off-beat (8th note triplets, velocity 45%)
- **Closed Hat:** Tight control on 2e/4e (ghost rim dynamics)
- **FX:** Vinyl crackle (layer +3 dB, 2–5 kHz band-pass)

#### Snare
- **Placement:** Hard on 3, ghost hits on 2e/4e
- **Tone:** Processed (EQ: +2 dB @ 3 kHz, -1 dB @ 8 kHz)
- **Reverb:** Short room (0.4s, -6 dB send)
- **Dynamics:** Transient-heavy, slight compression (4:1, fast attack)

---

### 🎹 Harmonic Layers

#### Chord Bed (Root Loop: 8 bars)

**Progression:**
```
Bar 1-2:  Cm(add9)  [C–E♭–G–D]
Bar 3-4:  A♭maj7    [A♭–C–E♭–G]
Bar 5-6:  B♭(sus2)  [B♭–C–F]
Bar 7-8:  Gm(add11) [G–D–C] + resolves to Cm
```

**MIDI Voicing (Low Register, 80–200 Hz):**
- Cm(add9): C2, G2, D3
- A♭maj7: A♭1, C2, G2
- B♭(sus2): B♭1, C2, F2
- Gm(add11): G1, D2, C2

---

#### Pad (Supersaw Synth)

**Texture:**
- **Oscillator:** 7-voice supersaw, slight detuning (±15 cents)
- **Filter:** Low-pass, Cutoff: 8–10 kHz (static)
- **LFO:** Slow sine wave (0.1 Hz) modulating cutoff ±800 Hz
- **Envelope:** ADSR (Attack 800ms, Decay 2s, Sustain 60%, Release 1s)
- **Reverb Send:** Hall (1.8s decay, -4 dB)
- **Sidechain:** Compressed 4–6 dB by kick (soft)

**MIDI:** Harmonic bed (as above), sustained whole notes

---

#### Lead (Reese-Style Mono Saw)

**Timbre:**
- **Oscillator:** Sawtooth, thick chorus (2 unison voices, 15ms detuning)
- **Filter:** Low-pass resonance (Q=6), cutoff envelope triggered per note
- **Pitch Envelope:** Attack +4 semitones (20ms), decay to base pitch (100ms)
- **Dynamics:** Soft saturation (gain +3 dB, tone 0.6)

**FX:**
- **Plate Reverb:** 1.4s decay, -8 dB send
- **Slap Delay:** 1/16 note (-12 dB, 1 repeat)

**MIDI Pattern (4-bar loop):**
```
Bar 1: C4 (quarter), G4 (eighth), D4 (quarter)
Bar 2: C4 (half)
Bar 3: G4 (quarter), C5 (eighth), G4 (quarter)
Bar 4: C4 (whole note, decay)
```

---

#### Texture/Atmosphere

- **Vinyl Hiss:** Noise sample, low-pass @ 12 kHz, 5% wet
- **Shortwave Static:** Filtered white noise (300–800 Hz band), 2–3% wet
- **Sidechain:** Both textures duck 1.5–2 dB to kick

---

### 🎛️ Vocal Chain (Reference)

**Signal Flow:**

1. **HPF (High-Pass Filter):** 80 Hz cutoff (removes sub rumble)
2. **Parametric EQ:** -3 dB @ 250 Hz (mud reduction), +1 dB @ 4 kHz (presence)
3. **Compressor:** 3:1 ratio, slow attack (30ms), medium release (150ms)
4. **De-Esser:** 7 kHz center, -6 dB reduction threshold (dynamic)
5. **Soft Saturator:** Gain +2 dB, tone 0.5 (warmth)
6. **Slap Delay:** 1/16 grid (-12 dB, 1 repeat)
7. **Hall Reverb:** 1.8s decay (-5 dB send)

**Master Out:** Limiter (ceiling -0.3 dB)

```

```
