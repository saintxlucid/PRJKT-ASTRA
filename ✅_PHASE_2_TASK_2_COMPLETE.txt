CORE IMPLEMENTATION DETAILS
─────────────────────────────────────────────────────────────────────────────

RiskLevel Classification:
  └─ LOW (0)      → Safe read operations, silent approval
  └─ NORMAL (1)   → Safe local operations, auto-approved + logged
  └─ HIGH (2)     → Write/delete operations, requires operator consent
  └─ CRITICAL (3) → Dangerous system ops, always requires explicit approval

OperatorRiskScorer:
  ├─ Tool baseline mapping (read_file=LOW, delete_file=CRITICAL, etc.)
  ├─ Argument pattern escalation:
  │  ├─ System paths (/etc, /sys, C:\Windows) → CRITICAL
  │  ├─ Wildcards (*, **) → CRITICAL
  │  └─ Recursive patterns (-r, --recursive) → Escalate
  └─ Returns: (RiskLevel, reason_string)

DryRunMode:
  ├─ Simulates execution without side effects
  ├─ Maintains execution log of all simulated actions
  ├─ Generates simulated output based on tool type
  └─ Async method: simulate_execution()

ConsentFlowManager:
  ├─ Consent policy per risk level:
  │  ├─ LOW → "silent" (no approval needed)
  │  ├─ NORMAL → "auto_approve" (automatic + log)
  │  ├─ HIGH → "require_consent" (operator approval)
  │  └─ CRITICAL → "always" (explicit approval required)
  ├─ Timeout-based approval mechanism (default: 60s)
  └─ Async method: request_consent()

AuditLogger:
  ├─ JSONL format (1 entry per line)
  ├─ Captures: timestamp, action, risk_level, approved, result
  ├─ Stores to: ./logs/agent_audit.jsonl (configurable)
  └─ Methods: log_action(), get_audit_log(limit=100)

LocalToolRegistry:
  ├─ 5 default tools (all LOW risk):
  │  ├─ read_file: Read file contents (async)
  │  ├─ list_dir: List directory (async)
  │  ├─ get_cpu_info: CPU metrics (async, psutil)
  │  ├─ get_memory_info: Memory metrics (async, psutil)
  │  └─ search_knowledge: Knowledge base search (async)
  ├─ Extensible registration: register(ToolDefinition)
  └─ Async execution: execute(tool_name, **kwargs)

SECURITY MODEL
─────────────────────────────────────────────────────────────────────────────

Risk Tiers:
  LOW (0-2):      Auto-approved, silent, read-only
  NORMAL (3-5):   Auto-approved, logged, safe local ops
  HIGH (6-8):     Manual approval required, write/delete ops
  CRITICAL (9-10): Always requires explicit approval, system ops

Escalation Triggers:
  └─ System paths: /etc, /sys, /proc, C:\Windows, C:\System
  └─ Wildcard patterns: *, **
  └─ Recursive flags: -r, --recursive
  └─ Unknown tools: Default to HIGH risk

Consent Policies:
  └─ LOW: Silent (no operator notification)
  └─ NORMAL: Auto-approve + log to audit
  └─ HIGH: Wait for operator approval (timeout=60s)
  └─ CRITICAL: Explicit denial by default (requires override)

Audit Trail:
  └─ Every action logged to JSONL
  └─ Captures: timestamp, tool, args, risk, approved, result
  └─ Supports compliance & forensics
