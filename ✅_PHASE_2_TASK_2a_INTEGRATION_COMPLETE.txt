INTEGRATION ARCHITECTURE
═══════════════════════════════════════════════════════════════════════════

LocalGPTOSManager.execute_agent_tool() Pipeline:

INPUT: agent_id, tool_name, arguments, [tool_registry]
   │
   ├─ 1. CREATE AgentAction
   │    └─ tool_name, arguments, agent_id, timestamp
   │
   ├─ 2. SCORE RISK
   │    └─ OperatorRiskScorer.score_action(action)
   │    └─ Returns: (RiskLevel, reason)
   │
   ├─ 3. SIMULATE EXECUTION
   │    └─ DryRunMode.simulate_execution(tool_name, arguments)
   │    └─ Returns: simulated_output dict
   │
   ├─ 4. REQUEST CONSENT
   │    └─ ConsentFlowManager.request_consent(action_id, action, risk_level)
   │    └─ Returns: approved (bool)
   │
   ├─ 5. EXECUTE IF APPROVED
   │    └─ IF approved: LocalToolRegistry.execute(tool_name, **arguments)
   │    └─ IF denied: Set error message
   │
   ├─ 6. LOG TO AUDIT
   │    └─ AuditLogger.log_action(action, risk_level, approved, result)
   │    └─ JSONL format persistent storage
   │
   └─ 7. RETURN RESPONSE
        └─ {
             "agent_id": str,
             "tool_name": str,
             "risk_level": str (LOW/NORMAL/HIGH/CRITICAL),
             "approved": bool,
             "result": Any,
             "audit_id": str,
             "execution_time_ms": float,
             "error": str | None
           }

RISK SCORING REFERENCE
═══════════════════════════════════════════════════════════════════════════

Tool Baseline Risks:

LOW RISK (0-2):
  • read_file
  • list_dir
  • search_knowledge
  • get_cpu_info
  • get_memory_info

HIGH RISK (6-8):
  • write_file
  • create_file
  • network_request
  • api_call

CRITICAL RISK (9-10):
  • delete_file
  • execute_command
  • run_subprocess
  • Any tool + system paths

Escalation Rules:
  • System paths (/etc, /sys, C:\Windows) → CRITICAL
  • Wildcards (*, **) → CRITICAL
  • Recursive flags (-r, --recursive) → Escalate
  • Unknown tools → DEFAULT to HIGH

Consent Policies:
  • LOW: Silent (no operator notification)
  • NORMAL: Auto-approve + log
  • HIGH: Manual approval required (60s timeout)
  • CRITICAL: Explicit approval mandatory
