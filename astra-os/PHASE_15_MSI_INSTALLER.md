## 🔧 Build Pipeline

### 1. Build Script (build.ps1)
**Purpose:** Compile Python → EXE using PyInstaller

```powershell
param(
    [string]$Version = "1.0.0",
    [string]$Channel = "stable",
    [switch]$Release = $false
)

# Step 1: Clean
Remove-Item -Path "build", "dist", "__pycache__" -Recurse -Force

# Step 2: Compile each component
@(
    "apps/bootd/__init__.py",
    "apps/core/__init__.py",
    "apps/autonomy/__init__.py",
    "apps/sentinel/__init__.py",
    "apps/gui/__init__.py"
) | ForEach-Object {
    pyinstaller --name=(Split-Path $_ -LeafBase) `
                --onefile `
                --windowed `
                --add-data "configs:configs" `
                $_
}

# Step 3: Copy libs
Copy-Item -Path "libs" -Destination "dist/libs" -Recurse

# Step 4: Version stamp
@"
VERSION = "$Version"
CHANNEL = "$Channel"
BUILD_DATE = "$(Get-Date -Format 'yyyy-MM-ddTHH:mm:ssZ')"
BUILD_ID = "$(git rev-parse --short HEAD)"
"@ | Out-File -Path "dist/VERSION"

Write-Output "✅ Build complete: $Version ($Channel)"
```

**Output:**
- `dist/bootd.exe`
- `dist/core.exe`
- `dist/autonomy.exe`
- `dist/sentinel.exe`
- `dist/gui.exe`
- `dist/libs/` (all Python libraries)

### 2. Package Script (package.ps1)
**Purpose:** Create MSI using WiX

```powershell
param(
    [string]$Version = "1.0.0",
    [string]$Channel = "stable"
)

# Step 1: Update WiX version
$wxs = Get-Content "installers/wix/AstraOS.wxs" -Raw
$wxs = $wxs -replace 'Version="[^"]*"', "Version=`"$Version`""
$wxs | Out-File -Path "installers/wix/AstraOS.wxs"

# Step 2: Generate MSI
& "C:\Program Files (x86)\WiX Toolset v3.11\bin\candle.exe" `
    -o "installers/msi/AstraOS.wixobj" `
    "installers/wix/AstraOS.wxs"

& "C:\Program Files (x86)\WiX Toolset v3.11\bin\light.exe" `
    -o "installers/dist/ASTRA-OS-Setup-$Version.msi" `
    "installers/msi/AstraOS.wixobj"

# Step 3: Create wrapper EXE
# (includes MSI + bootstrapper for auto-update)

Write-Output "✅ MSI created: installers/dist/ASTRA-OS-Setup-$Version.msi"
```

### 3. Sign Script (sign.ps1)
**Purpose:** Code sign EXE and MSI

```powershell
param(
    [string]$CertPath,
    [string]$CertPassword,
    [string]$FilePath
)

# Step 1: Sign using Authenticode
signtool sign /f $CertPath `
              /p $CertPassword `
              /t http://timestamp.digicert.com `
              $FilePath

# Step 2: Verify signature
signtool verify /pa $FilePath

Write-Output "✅ Signed: $FilePath"
```

### 4. Install Service Script (install_service.ps1)
**Purpose:** Register Windows Service after install

```powershell
param(
    [string]$ServiceName = "AstraOS",
    [string]$ServicePath = "C:\Program Files\ASTRA-OS\bootd.exe"
)

# Step 1: Create service account
$AccountName = "ASTRA_Service"
$Password = ConvertTo-SecureString -AsPlainText -Force "$(GenerateSecurePassword)"
New-LocalUser -Name $AccountName -Password $Password -Description "ASTRA-OS Service Account"

# Step 2: Grant minimal permissions
$acl = Get-Acl "C:\Program Files\ASTRA-OS"
$rule = New-Object System.Security.AccessControl.FileSystemAccessRule(
    "ASTRA_Service",
    "ReadAndExecute",
    "ContainerInherit,ObjectInherit",
    "None",
    "Allow"
)
$acl.SetAccessRule($rule)
Set-Acl "C:\Program Files\ASTRA-OS" $acl

# Step 3: Register service
New-Service -Name $ServiceName `
            -DisplayName "ASTRA-OS Companion" `
            -BinaryPathName $ServicePath `
            -StartupType Automatic `
            -ServiceAccount $AccountName

# Step 4: Configure service
$svc = Get-Service -Name $ServiceName
$svc | Set-Service -StartupType Automatic

Write-Output "✅ Service registered: $ServiceName"
```

### 5. Release Script (release.ps1)
**Purpose:** Automate release to multiple channels

```powershell
param(
    [string]$Version = "1.0.0",
    [string]$Channel = "stable",
    [string]$GitHubToken,
    [string]$Notes
)

# Step 1: Generate checksums
$files = Get-ChildItem "installers/dist/*"
$hash = @{}
$files | ForEach-Object {
    $hash[$_.Name] = (Get-FileHash $_ -Algorithm SHA256).Hash
}

# Step 2: Create release on GitHub
$releaseBody = @"
## ASTRA-OS $Version ($Channel)

$Notes

### Installation
\`\`\`powershell
ASTRA-OS-Setup-$Version.exe
\`\`\`

### Checksums (SHA256)
$($hash | ConvertTo-Json -Depth 1)

### Release Notes
- See CHANGELOG.md for details
"@

gh release create "v$Version" `
    --title "ASTRA-OS $Version ($Channel)" `
    --notes $releaseBody `
    $files

# Step 3: Upload SBOM
$sbom = Generate-SBOM
$sbom | Out-File "installers/dist/SBOM.spdx"
gh release upload "v$Version" "installers/dist/SBOM.spdx"

# Step 4: Update auto-update server
Update-UpdateServer -Version $Version -Channel $Channel

Write-Output "✅ Released: v$Version to $Channel channel"
```

## 🔐 Code Signing

### Obtaining Certificate
```
1. Purchase Authenticode certificate from DigiCert/Sectigo
2. Install on build machine
3. Store in: installers/certificates/astra_code_signing.pfx
```

### Signing Process
```powershell
# Sign EXE
signtool sign /f installers/certificates/astra_code_signing.pfx `
              /p (Get-Content installers/certificates/.pwd -Raw) `
              /t http://timestamp.digicert.com `
              dist/bootd.exe

# Verify signature
signtool verify /pa dist/bootd.exe
```
