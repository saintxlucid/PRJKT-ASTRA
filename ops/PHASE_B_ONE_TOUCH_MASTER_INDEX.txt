🚨 EMERGENCY SCENARIOS (Decision Trees)

SCENARIO 1: Predeploy Gates Fail (T-0, before go-live)
  Decision: Can we fix in <30 min?
  ├─ YES: Use gate-failure fix matrix (GO_NO_GO_PROTOCOL.md or QUICK_REF.txt)
  │   Fix issue, re-run predeploy, get gates to 7/7 PASS
  ├─ NO: Delay deployment to tomorrow
  │   Notify team, schedule post-incident review, investigate overnight
  └─ Result: Either 7/7 PASS or NO-GO (no deployment today)

SCENARIO 2: Error Rate >2% During Deployment (T+5 to T+30)
  Decision: Immediate
  └─ Action: Execute rollback NOW
     └─ Command: pwsh ops\fusion_pipeline\scripts\07_roll_back.ps1
     └─ Result: Phase A restored within 1 minute
     └─ Next: Root cause investigation after rollback complete

SCENARIO 3: CODE Canary Accepted Instead of Rejected (T+25)
  Decision: Immediate CRITICAL
  └─ Action: ROLLBACK IMMEDIATELY (firewall bypass = security breach)
     └─ Command: pwsh ops\fusion_pipeline\scripts\07_roll_back.ps1
     └─ Next: Security incident investigation (URGENT)
     └─ Message: "Consent firewall failure detected. Phase-B compromised."

SCENARIO 4: Sacred Code 333 Not in Logs (T+45)
  Decision: Investigate quickly
  ├─ Check: grep -i "sacred" logs/*.log | wc -l
  ├─ If 0: Audit trail broken (security concern)
  │   └─ Action: Escalate to security + decision maker
  │   └─ May recommend rollback (investigate first)
  ├─ If sparse: Logging issue (may be OK)
  │   └─ Action: Monitor, log for post-incident review
  └─ Continue: Only rollback if 0 and confirmed broken

SCENARIO 5: Latency Trending Up (T+30)
  Decision: Wait and watch
  ├─ Monitor: Next 5-10 minutes
  ├─ If continues climbing: Investigate memory + CPU
  │   └─ Action: Check for memory leak (see FIRST_HOUR_WATCH.txt)
  │   └─ If yes: Rollback (memory leak)
  │   └─ If no: Continue monitoring
  ├─ If stabilizes: OK, continue
  └─ Escalate: If trending >50% above baseline

SCENARIO 6: Prometheus Metrics All Zero (T+10)
  Decision: Router not logging?
  └─ Investigation:
     └─ Check: Is health endpoint responding? (curl endpoint)
     └─ Check: Are requests arriving? (check app logs)
     └─ If health down: ROLLBACK (router broken)
     └─ If requests not arriving: Upstream issue (not deployment failure)
