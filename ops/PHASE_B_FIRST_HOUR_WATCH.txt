🚨 DECISION TREE: What to Do If a Signal Goes Red

1. ERROR RATE SPIKES ABOVE 1%
   → Step 1: Check error types in Prometheus
   → Step 2: Look up error in logs/phase_b_launch.log
   → Step 3: 
      If "model_timeout" or "fusion_pipeline_error": ROLLBACK
      If "consent_bypass": ROLLBACK IMMEDIATELY (security)
      If "router_dispatch_error": ROLLBACK (core broken)
      If isolated request failures: MONITOR (may be transient)

2. LATENCY EXCEEDS TOLERANCE
   → Step 1: Check which route (TEXT vs VISION/AUDIO)
   → Step 2: Look at CPU & memory (resource bottleneck?)
   → Step 3:
      If TEXT p95 > 1300ms + memory >+5%: ROLLBACK (leak + slowdown)
      If VISION/AUDIO p95 > 2200ms: Investigate tool latency
      If CODE rejection > 1000ms: Check consent firewall
      If isolated spike then recovery: MONITOR (transient)

3. MEMORY GROWS > +3%
   → Step 1: Check memory_items breakdown (semantic/episodic/procedural)
   → Step 2: Look for memory_bridge.py errors in logs
   → Step 3:
      If memory climbing continuously: ROLLBACK (memory leak)
      If memory stable then growth: MONITOR (normal operation)
      If CPU also high: Resource contention, may need restart

4. SACRED CODE 333 NOT APPEARING
   → Step 1: Check logs for astra_router_* events
   → Step 2: Verify AstraRouter initialization
   → Step 3:
      If NO 333 events anywhere: ROLLBACK (audit trail broken, security violation)
      If sparse 333 events: Investigate logging (may be fine)

5. CONSENT BLOCKS = 0 (CODE CANARY EXPECTED 1+)
   → Step 1: Run code canary manually (verify it's rejecting)
   → Step 2: Check consent configuration in production
   → Step 3:
      If canary is rejected locally but metric = 0: Logging bug (investigate)
      If canary bypassed: ROLLBACK IMMEDIATELY (firewall broken, security violation)

6. ROUTE HITS FLAT (NOT INCREMENTING)
   → Step 1: Check if requests are arriving at router
   → Step 2: Look at error rate (if spiking, requests failing)
   → Step 3:
      If requests arriving but hits not incrementing: ROLLBACK (measurement broken)
      If errors spiking: See ERROR RATE section above
      If no requests: Check client/upstream system
