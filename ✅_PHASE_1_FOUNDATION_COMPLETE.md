## 🏗️ Architecture Overview

### Core Components

**1. Cognitive Fusion (Phase 1A)**
- MetaController routes tasks to optimal reasoning mode
- CognitiveGovernor adjusts creativity based on risk
- LucidWeights configure philosophical alignment
- Risk classification (HIGH/MEDIUM/LOW)

**2. Macro Mining (Phase 1B)**
- ExecutionTrace records every task execution
- MacroMiner identifies repeating patterns
- DSL generation for procedural macros
- Nightly learning service (3:00 AM)

**3. Telemetry Collection (Phase 1C.1)**
- TelemetryCollector tracks real-time metrics
- TelemetrySnapshot captures aggregated data
- P95 latency calculation
- Mode distribution tracking

**4. Nightly Refinement (Phase 1C.2)**
- RefinementEngine analyzes telemetry history
- PolicyChange proposals with rationale
- Budget/macro/latency/emotion analysis
- Operator approval required

### Self-Evolution Loop

```
┌─────────────────────────────────────────────────────────────┐
│  DAY: Execution with Cognitive Fusion                       │
│  ├─► Task routing (MetaController)                          │
│  ├─► Trace recording (MacroMiner)                           │
│  ├─► Telemetry collection (TelemetryCollector)              │
│  └─► Snapshot persistence (save_telemetry_snapshot)         │
│                                                             │
│  NIGHT: Automated Learning & Optimization                   │
│  ├─► 03:00 AM: Macro learning (run_nightly_macro_learning) │
│  │   └─► Generate DSL proposals from traces                │
│  ├─► 03:15 AM: Refinement (run_nightly_refinement)         │
│  │   └─► Analyze telemetry, propose policy changes         │
│  └─► 03:30 AM: Memory compression (Phase 3)                │
│                                                             │
│  MORNING: Operator Review & Approval                        │
│  ├─► Review macro proposals                                 │
│  ├─► Review policy changes                                  │
```

## 🚀 Production Deployment

### Scheduling Nightly Tasks

**Windows Task Scheduler:**
```powershell
schtasks /create /tn "ASTRA Macro Learning" /tr "python -m chat_os.services.nightly_tasks macro" /sc daily /st 03:00
schtasks /create /tn "ASTRA Refinement" /tr "python -m chat_os.services.nightly_tasks refinement" /sc daily /st 03:15
```

**Linux/macOS cron:**
```bash
0 3 * * * cd /path/to/astra && python -m chat_os.services.nightly_tasks macro
15 3 * * * cd /path/to/astra && python -m chat_os.services.nightly_tasks refinement
```

### Manual Testing

**Macro Learning:**
