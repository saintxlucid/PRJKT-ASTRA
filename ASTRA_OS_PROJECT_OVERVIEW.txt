  🎯 PROJECT VISION
================================================================================

Build ASTRA-OS: A persistent Windows daemon that gives ASTRA a system-level
presence. Instead of a FastAPI service, ASTRA becomes an always-running AI
companion that:

✅ Boots with Windows
✅ Monitors system events (files, processes, network)
✅ Provides a professional GUI dashboard
✅ Makes autonomous decisions (with user control)
✅ Learns from feedback
✅ Detects and responds to security threats
✅ Respects user autonomy preferences

================================================================================
  🚀 HOW TO RUN ASTRA-OS
================================================================================

Requirements:
  - Python 3.8+
  - Windows OS
  - Dependencies: PyQt6, psutil, structlog, pywin32, watchdog

Installation:
  pip install PyQt6 psutil structlog pywin32 watchdog

Running the Daemon:
  cd x:\PROJECT_ASTRA_2.0\PROJECT_ASTRA_1.0 (ASTRA_CORE)
  python -m astra.daemon.boot_daemon

Expected Behavior:
  1. Daemon starts in background
  2. PyQt6 GUI window appears
  3. System Monitor tab shows live CPU/memory/disk
  4. Metrics update every 2 seconds
  5. Settings allow autonomy adjustment (1-5)
  6. (Phase 3) Memory Insights will show decisions
  7. (Phase 4) Security Status will show threats

Auto-Start on Windows Boot:
  1. Daemon automatically registers in HKCU\Run
  2. Next reboot: ASTRA-OS starts automatically
  3. GUI appears after boot (or runs headless if no display)

================================================================================
  🎓 DEVELOPER GUIDE
================================================================================

Adding New Metrics to System Monitor:

  1. Add to SystemMetrics dataclass:
     @dataclass
     class SystemMetrics:
         new_metric: float

  2. Collect in _update_metrics():
     new_value = some_measurement()

  3. Display in SystemMonitorTab:
     self.new_label = QLabel(f"New: {metrics.new_metric}")

Adding New Tab to GUI:

  1. Create new class inheriting from QWidget
  2. Implement init_ui() method
  3. Add to AstraOperatorWindow.init_tabs():
     self.new_tab = NewTab()
     tabs.addTab(self.new_tab, "Tab Name")

Integrating Vosk Voice Recognition:

  1. Install: pip install vosk
  2. Uncomment code in VoiceWorker.run()
  3. Connect to command handlers
  4. Test wake words

Connecting Phase 3 Training Loop:

  1. Create training_loop.py (250 lines)
  2. Make decisions based on EventBus events
  3. Call shell.add_decision(decision_dict)
  4. Watch Memory Insights tab populate
