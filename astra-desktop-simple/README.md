# ASTRA Desktop - Simple & Working

A lightweight Electron desktop launcher for ASTRA.

## Quick Start

```bash
cd astra-desktop-simple
npm install
npm start
```

## Build Installer

```bash
npm run build
```

Output: `dist\ASTRA Desktop Setup 1.0.0.exe`

## Features

✅ System tray integration
✅ Backend auto-start
✅ Lightweight (minimal dependencies)
✅ Clean, modern UI
✅ Windows installer ready

## What It Does

1. Checks if ASTRA backend is running
2. Auto-starts backend if needed  
3. Provides a dashboard to launch console, settings, etc.
4. Runs in system tray when closed
