ARCHITECTURAL HIGHLIGHTS
═══════════════════════════════════════════════════════════════════════════════

1. PLUGIN SYSTEM ARCHITECTURE

   AstraPlugin (Base)
        ↓
   PluginLoader (Discovery)
        ↓
   Consent Wrapper (Enforcement)
        ↓
   Tool Registry (Integration)
        ↓
   Capability Invocation

   Key Features:
   - Dynamic discovery from plugins/ directories
   - Consent-gated execution (per-plugin flag)
   - Health monitoring and metadata
   - Graceful initialization/shutdown
   - Type-safe capability registration

2. EMOTIONAL RADAR ARCHITECTURE

   Prometheus Metrics
        ↓
   Signals API (/emotion, /cognitive, /system)
        ↓
   WebSocket / Polling
        ↓
   EmotionalRadar Component
        ↓
   Recharts Radar Visualization

   Key Features:
   - Real-time signal streaming
   - 0.0-1.0 normalized values
   - Threshold-based alerts
   - Overall state indicator
   - Customizable color schemes

3. AUTO-BOOT ARCHITECTURE

   Windows:
   Task Scheduler → SYSTEM User → Python.exe → astra_launcher.py
   
   Linux:
   systemd → astra.service → astra User → python3 → astra_launcher.py
   
   Both:
   - Auto-restart on failure
   - Logging (Event Viewer / journalctl)
   - Graceful shutdown handling
   - Resource management

4. AUDIO ANALYSIS ARCHITECTURE

   WAV/MP3 Input
        ↓
   librosa.load() (44.1kHz, mono)
        ↓
   ┌─────────┬────────────┬──────────────┐
   │ BPM Map │ Freq Bands │ Sections     │
   └─────────┴────────────┴──────────────┘
        ↓           ↓            ↓
   CSV Outputs (bpm_map, bands, sections)
        ↓
   Report Template (BEAT_VERSE_REPORT)

   Key Features:
   - Beat timing with instantaneous BPM
   - 6 frequency band energy tracking
   - Novelty-based section detection
   - Professional report format
