- **Risk-aware governor**: Throttles creativity based on task risk level
- **Decision latency**: <10ms routing decisions

#### 2. Lucid Protocol Alignment (`astra_core/lucid_protocol.py`)
- **4 philosophical vectors**: truth↔compassion, logic↔intuition, order↔freedom, efficiency↔safety
- **Tone steering**: Error messages adapt based on alignment weights
- **Priority routing**: Action sequencing follows operator values
- **Integration-ready**: Clean API for identity system

#### 3. Emotional Context Engine (`astra_core/emotion/context_engine.py`)
- **Local-only sensing**: Ambient noise, typing rhythm, time-of-day
- **4 energy states**: Focused, Fatigued, Stressed, Exploratory
- **UI adaptation hints**: Warmth, brightness, verbosity modulation
- **Privacy-first**: No recording, ephemeral processing
- **Test coverage**: 1/1 inference test passing

#### 4. Macro Mining Engine (`astra_core/macro_mining.py`)
- **Pattern detection**: Learns from repeated successful execution traces
- **Confidence thresholds**: Configurable min-occurrences and success rates
- **DSL generation**: Human-readable macro specifications
- **Test coverage**: 3/3 mining tests passing

#### 5. Nightly Refinement Engine (`astra_core/refinement.py`)
- **Telemetry analysis**: Budget pressure, latency, emotional trends
- **Policy proposals**: Auto-generated optimization recommendations
- **Operator consent gates**: No changes without explicit approval
- **Test coverage**: 4/4 refinement tests passing

#### 6. Semantic Compression (`astra_core/memory/semantic_compression.py`)
- **Concept bucketing**: Deterministic embedding → graph formation
- **On-demand rehydration**: Fast recall of compressed memories
- **Foundation for dreaming**: Nightly background compression ready

#### 7. PQ Token Interface (`astra_core/security/pq_token.py`)
- **Dilithium-ready design**: Hybrid classical+PQ signature interface
- **HMAC fallback**: Immediate deployment with SHA-256
- **PID binding**: Process-level security isolation
- **TTL enforcement**: Time-bound token validity

#### 8. Forge Sandbox (`astra_core/forge/sandbox.py`)
- **Resource-limited execution**: CPU, memory, file size constraints
- **Timeout protection**: Prevents runaway processes
- **Safe by default**: Restricted imports, temp-dir only writes
