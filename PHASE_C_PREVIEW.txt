Create: scripts/embed_gguf_metadata.py

Script responsibilities:
  1. Load GGUF model
  2. Extract current metadata
  3. Add 67-field schema
  4. Add 36 deep reflections
  5. Add 24 special tokens
  6. Validate all additions
  7. Save updated model
  8. Verify integrity

Pseudo-code:
  import gguf
  from astra.core.astra_router import DEEP_REFLECTIONS, SPECIAL_TOKENS
  
  model_path = "path/to/model.gguf"
  backup_path = model_path + ".backup"
  
  # Backup original
  shutil.copy(model_path, backup_path)
  
  # Load model
  model = gguf.load(model_path)
  
  # Add metadata schema (67 fields)
  for field_name, field_value in METADATA_SCHEMA.items():
      model.metadata[field_name] = field_value
  
  # Add deep reflections (36 facts)
  model.metadata['deep_reflections'] = DEEP_REFLECTIONS
  
  # Add special tokens (24)
  for token in SPECIAL_TOKENS:
      model.add_token(token)
  
  # Save updated model
  model.save(model_path)
  
  # Verify
  assert model.metadata['sacred_code'] == "333"
  print("✅ GGUF metadata embedded successfully")
