## 🚨 CRITICAL ISSUES & QUICK RESPONSE

### If Validator Script Fails

**Problem**: Can't find logs or metrics
- **Solution**: Ensure logs/astra.log exists with 24h data from Oct 18 7:15 PM
- **Action**: Check: `Get-ChildItem logs/astra.log; Get-Content logs/astra.log -Tail 5`

### If Latency Gate Fails

**Problem**: p95 TEXT > 1050ms
- **Solutions**:
  - Switch quant: q4_k_m → q5_k_m (faster but less accuracy)
  - Reduce max_tokens: 512 → 256
  - Lower image sizes (if VISION spike)
- **Action**: Update config.yaml, restart, re-test

### If Consent Gate Fails

**Problem**: Unauthorized code executions detected
- **Action**: Rollback immediately
- **Reason**: Security breach; investigate before re-attempting

### If Error Rate Fails

**Problem**: >1.5% error rate detected
- **Action**: Don't proceed with Phase B
- **Debug**: Check error patterns in logs; identify root cause

### If ANY Gate Fails

**Protocol**:
1. Don't proceed to Phase B
2. Apply hotfix (if applicable) or rollback
3. Re-run validator after fix
4. If still failing after 2h: Escalate & investigate
