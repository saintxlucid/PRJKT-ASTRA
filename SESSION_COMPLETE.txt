════════════════════════════════════════════════════════════════════════════════
  DECISION FLOW: HOW IT WORKS
════════════════════════════════════════════════════════════════════════════════

System Event Occurs
        ↓
"File created: Desktop/suspicious.exe"
        ↓
OS Kernel detects → emits event via EventBus
        ↓
Training Loop receives event
        ↓
DecisionEngine evaluates:
  - Finds matching rule: "rule_block_suspicious_exe"
  - Confidence: 0.85
  - Action: ask_user
  - Reason: "Ask user before allowing suspicious executable"
        ↓
Decision created with full context
        ↓
LearningEngine stores decision in history
        ↓
Decision sent to OperatorShell
        ↓
GUI displays in Memory Insights tab
        ↓
User sees decision and clicks "APPROVE"
        ↓
LearningEngine receives feedback
  - Confidence increases: 0.85 → 0.90
  - Approval count: +1
  - Rule updated and saved
        ↓
Next similar event:
  - Uses updated rule (confidence 0.90)
  - If user approves again: 0.90 → 0.95
  - After multiple approvals and high autonomy level:
    - Auto-acts without asking (seamless)
        ↓
RESULT: System learned to trust this action ✅
